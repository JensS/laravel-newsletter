# Contributing

Thanks for helping! Please:

1. Open an issue first for larger changes so we can agree on the approach.
2. Add or update tests: `composer test` must pass.
3. Keep the package dependency-light and shared-hosting friendly (no Redis, no long-running daemons required).
4. Follow the existing code style (PSR-12 / Laravel Pint defaults).

Security issues: please do not open a public issue. Use GitHub's private vulnerability reporting for this repository instead.
